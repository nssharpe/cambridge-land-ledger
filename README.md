# Cambridge Land Ledger

An open look at where Cambridge, MA land value sits, whether it is valued accurately, and what a land/building tax shift would actually do here. Built by Nate Sharpe, a Cambridge resident (disclosure: lives in a condo building).

Data: City of Cambridge FY2026 assessor data and parcels; OpenStreetMap; MassGIS L3 parcels. Static site; no tracking.
